---
title: "Switch Abstraction Interface (SAI)"
description: "A vendor-independent C API for controlling network forwarding elements — switching ASICs, NPUs, and software switches — in a uniform manner."
---

SAI (Switch Abstraction Interface) defines a standard C API that allows control plane software to manage network forwarding elements — such as switching ASICs, NPUs, and software switches — without being tied to any specific hardware vendor. It is the foundation of [SONiC](https://github.com/sonic-net/sonic-buildimage) and is maintained by the Open Compute Project.

## Core concepts

<CardGroup cols={2}>
  <Card title="Object model" icon="cubes" href="/concepts/object-model">
    Every forwarding element is represented as a SAI object with a unique 64-bit object ID.
  </Card>
  <Card title="Attributes" icon="sliders" href="/concepts/attributes">
    Attributes are key-value pairs used for all create, get, and set operations.
  </Card>
  <Card title="Adapter" icon="plug" href="/concepts/adapter">
    An Adapter is a vendor-provided shared library that implements SAI for a specific ASIC.
  </Card>
  <Card title="Extensions" icon="flask" href="/concepts/extensions">
    Use the extension mechanism to add experimental or vendor-specific functionality.
